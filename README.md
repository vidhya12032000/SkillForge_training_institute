# SkillForge – Typing & Computer Training Institute

SkillForge is a modern and responsive website for a Typing & Computer Training Institute. It includes course information, student and admin dashboards, typing performance tracking, progress monitoring, and certificates.

## ✨ Features

- Responsive Website
- Student Dashboard
- Admin Dashboard
- Course & Student Management
- Typing Speed & Accuracy Tracking
- Learning Progress & Timetable
- Certificates
- Dark Mode
- RTL Support
- LocalStorage

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Font Awesome / Lucide Icons

## 🚀 How to Run

1. Download or clone the project.
2. Open the project in VS Code.
3. Open `index.html` using Live Server.
